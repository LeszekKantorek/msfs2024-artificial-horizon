## Select a change across components

Select a row by the behavior being changed, then follow its contracts and checks.
Apply the [validation scope matrix](../docs/testing/index.md#validation-by-change-scope) to every affected boundary.
Use the [decision map](architecture-decisions.md#find-the-governing-decision) when reconsidering an accepted choice.

| Change | Read first | Validation | Extend only when relevant |
| --- | --- | --- | --- |
| Change sample expiry or unavailable indications | [Freshness and distribution](../docs/architecture.md#latest-state-distribution), [freshness and age](../docs/telemetry-contract.md#freshness-and-status) | [Telemetry checks](../docs/testing/runtime.md#telemetry-and-demo-checks), [SSE and controller checks](../docs/testing/runtime.md#sse-and-browser-controller-checks) | [Frame lifecycle](../docs/efi/lifecycle.md#panel-interface-and-frame-lifecycle) when expiry affects scheduled drawing |
| Change reconnect or background/resume behavior | [Session lifecycle](../docs/architecture.md#browser-connection-lifecycle), [browser lifecycle decision](../docs/adr/0002-sse-connection-lifecycle.md#browser-lifecycle) | [SSE and controller checks](../docs/testing/runtime.md#sse-and-browser-controller-checks), [real-phone procedure](../docs/testing/devices.md#real-phone-acceptance-procedure) | [Unavailable presentation](../docs/efi/status.md#requirements-and-presentation) when changing the cover or status display |
| Change shutdown, cancellation, or producer failure | [Application lifecycle](../docs/architecture.md#application-lifecycle), [application composition](../docs/architecture.md#application-composition) | [HTTP startup and shutdown checks](../docs/testing/runtime.md#http-startup-checks) | [Composition decision](../docs/adr/0007-application-composition.md#decision); [connection shutdown](../docs/server.md#connection-shutdown) when open connections can delay shutdown |
| Change delivery to slow clients or SSE framing | [SSE delivery](../docs/server.md#sse-delivery), [wire framing](../docs/telemetry-contract.md#framing) | [SSE checks](../docs/testing/runtime.md#sse-and-browser-controller-checks) | [Socket deadlines](../docs/adr/0002-sse-connection-lifecycle.md#socket-deadlines) for stalled writes; [device measurements](../docs/testing/evidence.md#measurements-and-evidence) for latency claims |
| Change asset routes or health responses | [Server routes](../docs/server.md#http-routes), [embedded assets](../docs/server.md#embedded-assets) | [HTTP startup checks](../docs/testing/runtime.md#http-startup-checks) | [Delivery boundaries](../docs/efi/composition.md#delivery-boundaries) when browser imports change |
| Change deterministic Demo scenarios | [Demo API and scenarios](../docs/sources/demo.md) | [Telemetry and Demo checks](../docs/testing/runtime.md#telemetry-and-demo-checks) | [EFI feature checks](../docs/efi/index.md#features) when scenario values exercise an indication |
| Add or change a telemetry field | [Model boundary](../docs/telemetry-contract.md#model-boundary), [field conventions](../docs/telemetry-contract.md#fields-and-conventions), [compatibility](../docs/telemetry-contract.md#compatibility) | [Telemetry fixtures](../docs/testing/runtime.md#fixtures-and-tests) | [Presentation map](../docs/efi/index.md#features) and [feature checks](../docs/testing/index.md#find-the-required-procedure) when the field affects an indication |
| Add or replace a telemetry provider | [Source responsibilities](../docs/sources/index.md#shared-responsibilities), [library telemetry interface](../docs/architecture.md#library-telemetry-interface) | [Telemetry checks](../docs/testing/runtime.md#telemetry-and-demo-checks), [startup checks](../docs/testing/runtime.md#http-startup-checks) | [SimConnect integration](../docs/sources/simconnect.md) and [simulator acceptance](../docs/testing/devices.md#manual-acceptance-matrix) for a real simulator source |
| Move rendering, scheduling, or visual-object responsibilities | [Shared presentation responsibilities](../docs/efi/index.md#shared-responsibilities), [presentation map](../docs/efi/index.md#features) | [project-validate-presentation](../.agents/skills/project-validate-presentation/SKILL.md), [composition acceptance](../docs/testing/pfd.md#modular-and-layered-efi-acceptance) | [Telemetry operations](../docs/efi/telemetry.md#telemetry-operations) when changing acceptance or invalidation of samples |
| Change the listen address or network exposure | [Deployment](../docs/architecture.md#deployment), [HTTP configuration](../docs/server.md#configuration) | [HTTP startup checks](../docs/testing/runtime.md#http-startup-checks) | [Security boundaries](security-review.md#project-boundaries) when changing access or trust; [phone setup](../README.md#use-your-phone) when changing LAN instructions |

This map routes changes without adding requirements.
